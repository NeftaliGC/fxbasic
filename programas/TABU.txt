## ===== 3: GENERAR VECINOS (Mat C) =====
Lbl 3
ClrText
"1:SWAP 2:INSERCION"
"3:2-OPT"
"TIPO"?→M
"FIJAR POS 1?(1=SI)"?→G
1→B
G=1⇒2→B
N-B+1→Q
(Q-1)²→K
M≠2⇒Q(Q-1)÷2→K
ClrMat C
{K,N+3}→Dim Mat C
0→K
## --- swap: intercambia posiciones I y J ---
If M=1
Then
For B→I To N-1
For I+1→J To N
K+1→K
For 1→P To N
List 1[P]→Mat C[K,P]
Next
List 1[J]→Mat C[K,I]
List 1[I]→Mat C[K,J]
List 1[I]→X
List 1[J]→Y
If X>Y
Then
X→S
Y→X
S→Y
IfEnd
X→Mat C[K,N+1]
Y→Mat C[K,N+2]
Mat T[X,Y]→Mat C[K,N+3]
Next
Next
IfEnd
## --- insercion: mueve el elemento de la pos I a la pos J ---
If M=2
Then
For B→I To N
For B→J To N
If (J-I)(J-I+1)≠0
Then
K+1→K
For 1→P To N
List 1[P]→Mat C[K,P]
Next
If J>I
Then
For I→P To J-1
List 1[P+1]→Mat C[K,P]
Next
Else
For J+1→P To I
List 1[P-1]→Mat C[K,P]
Next
IfEnd
List 1[I]→Mat C[K,J]
List 1[I]→X
X→Mat C[K,N+1]
J→Mat C[K,N+2]
Mat T[X,J]→Mat C[K,N+3]
IfEnd
Next
Next
IfEnd
## --- 2-opt: invierte el tramo entre las pos I y J ---
If M=3
Then
For B→I To N-1
For I+1→J To N
K+1→K
For 1→P To N
List 1[P]→Mat C[K,P]
Next
For 0→P To J-I
List 1[J-P]→Mat C[K,I+P]
Next
I→Mat C[K,N+1]
J→Mat C[K,N+2]
Mat T[I,J]→Mat C[K,N+3]
Next
Next
IfEnd
ClrText
Locate 1,1,"VECINOS:"
Locate 10,1,K
Locate 1,2,"ESTAN EN MAT C"
Locate 1,3,"1 FILA = 1 VECINO"
Locate 1,7,"EXE:MENU"
While Getkey≠31
WhileEnd
Goto 0
